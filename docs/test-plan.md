## 单次记录格式

复制这一结构时填写实际内容，未执行项写“未执行”，不要虚构数据：日期与操作者；程序和提交号；供电/接线；场地和步骤；期望现象；实际现象；是否通过；证据位置；问题与下次动作。

## 已发现的原厂边界

静态检查 `02.2_Ultrasonic_Ranging` 发现其距离数组为 8 位类型，无法完整表达函数设置的 1000 cm 无回波返回值；且示例会自动扫描舵机角度。当前保持原厂快照不改动，以便建立对照。后续自主导航代码必须单独处理超时/无回波，不把这一示例直接作为可靠障碍检测实现。该问题来自代码审阅，不是实车故障报告。
