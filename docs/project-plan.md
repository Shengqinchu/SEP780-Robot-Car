# 项目计划

## 已确定的方向

使用现有 Freenove FNK0041 小车。先验证组装、基础运动、循迹、超声波和遥控，不为基础阶段增加 Raspberry Pi 或摄像头。旧 AutoRC 仅保留为后续参考，此仓库尚未移植其代码。

## 推荐的改进范围，尚未定案

在原厂能力基础上，优先考虑明确的模式切换、遇障停车/恢复、脱线处理、通信超时停止，以及可复现的测试记录。重点是自己实现并解释决策逻辑、对比原厂行为，而不是把套件例程换个名字。

标记视觉识别是可选扩展，不是当前依赖：只有基础版本稳定、老师认可范围且时间/预算允许时，再评估电脑端 OpenCV 与车端通信。现阶段未购买视觉硬件，也没有承诺最终采用视觉路线。

## 工具选型补充（2026-09-13）

[深入调研](tooling-research.md) 已完成：继续以 Arduino CLI 为构建依据，采用受控 pySerial 会话；状态机测试留待车端实现。MCP 只在有实际接入需求时加一层，候选 MCP/Skill 尚未安装。调研当时仅枚举串口，后续已完成下述 COM5 上传/通信验证；当前 CLI 配置的 Uno 不支持开箱即用的断点调试。

基础版建议围绕循迹、障碍停车、脱线处理、远程超时停止和可复现日志组织，而不是叠加全部高星框架。OpenCV/标记与语音仍为可选扩展，实际实施需要先确认视频/音频来源和老师认可的范围。

## 主机工具实施补充（2026-09-13）

已实施 [USB 串口自动调试](serial-automation.md)：pySerial 3.5 独立环境、43 项离线测试、限时采集/握手、上传与串口共用锁、原始记录落档。主机测试使用 Python unittest；Unity 留待独立车端决策模块开始实现时再导入，未为了清单完整而安装无用依赖。

后续已在 COM5 成功上传 USB 检查程序并完成实际查询/连续心跳验证。组装接线可保留，USB-only 条件为无电池或外接电源、车板 POWER 关和蓝牙移除，不再要求逐个拔线。MCP、视觉和状态机尚未实施，不能把主控检查完成描述为课程项目完成。
